# E4OT: Eggshell for Osteoarthritis Treatment 
**Extracting high-value biomedical acids from food waste.**

### 📌 Overview
Osteoarthritis injections are expensive ($400-$800). This project provides a sustainable alternative by extracting **Hyaluronic Acid (HA)** from eggshell membranes, a common waste product.

### 🧪 Methodology
1. **Dissolution:** HCl is used to dissolve the calcium carbonate.
2. **Digestion:** Pepsin and phosphate buffers are used to break down proteins.
3. **Precipitation:** Arduino-controlled temperature regulation for precise HA precipitation.

### 📈 Results
- **Efficiency:** Extracted ~5% Hyaluronic Acid per 1g of eggshell.
- **Social Impact:** Provides a low-cost medical solution while reducing greenhouse gas emissions from decomposing food waste.
